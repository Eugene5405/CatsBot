# 🛡 Хранитель чата — Telegram-бот для модерации, игр и экономики

Многофункциональный Telegram-бот на **Python 3.11+ (`aiogram 3`)** и **PostgreSQL (Neon)** с встроенной веб-панелью управления (**Telegram Mini App**). Сочетает строгую автомодерацию, систему репортов, репутацию, валюту «Алиби», магазин на 13 товаров, ролеплей и апелляции.

## 🚀 Быстрый запуск (GitHub + Neon + Render)

1. **Создай бота в Telegram.** Открой [@BotFather](https://t.me), создай бота через `/newbot`, скопируй `BOT_TOKEN`. В **Bot Settings → Group Privacy** выбери **Turn off**, чтобы бот видел команды без слэша.
2. **Создай базу данных в Neon.** Зарегистрируйся на [neon.tech](https://neon.tech), создай бесплатный проект PostgreSQL и скопируй строку подключения (`postgresql://...`).
3. **Задеплой на Render.** Создай **Web Service** на [render.com](https://render.com), подключи этот репозиторий и укажи:
   * **Build Command:** `pip install -r requirements.txt`
   * **Start Command:** `python main.py`
4. **Добавь переменные окружения на Render:**
   * `BOT_TOKEN` — токен из BotFather
   * `DATABASE_URL` — строка подключения из Neon
   * `CHANNEL_ID` — ID канала для проверки подписки (необязательно)
   * `OWNER_ID` — твой Telegram ID для уведомлений о добавлении бота в чаты
5. **Настрой пингер 24/7.** Создай бесплатную задачу на [cron-job.org](https://cron-job.org), которая каждые 5–10 минут пингует `https://<твой-сервис>.onrender.com/`, чтобы сервер не засыпал.

## ✨ Основные команды
* **Для всех:** `/rules`, `/warns`, `/bag` (баланс), `/shop`, `+реп`, `/marry`, «русская рулетка», РП-команды.
* **Для админов:** `бан`, `мут`, `варн`, `анмут`, `разбан`, `/settings`, `/status`, `/tickets`.
*(Кулдауны на наказания: мут и предупреждение — раз в 3 часа, бан — раз в 8 часов на одного человека. Создателя чата это не касается).*
